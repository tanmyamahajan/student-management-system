# Student Management System

A console-based Student Management System built using **Core Java** and **Object-Oriented Programming (OOP)**.

## 📌 About the Project

This project allows users to manage student records through a simple console-based interface.

It was built to practice Java fundamentals and understand how Object-Oriented Programming concepts can be applied to a practical application.

## ✨ Features

- Add student records
- View student records
- Search for a student
- Update student information
- Delete student records
- Console-based user interaction

## 🛠️ Technologies Used

- Java
- Core Java
- Object-Oriented Programming

## 🧠 Concepts Practiced

- Classes and Objects
- Encapsulation
- Constructors
- Methods
- Array / ArrayList
- Loops and Conditional Statements
- Exception Handling
- Java Collections

## ▶️ How to Run

1. Clone the repository.
2. Open the project in an IDE such as IntelliJ IDEA or VS Code.
3. Compile and run the main Java class.
4. Follow the instructions displayed in the console.
